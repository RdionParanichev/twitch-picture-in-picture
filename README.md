# Twitch Picture in Picture

Расширение для настольного Chromium / Google Chrome: стримы и VOD Twitch в штатном окне «Картинка в картинке».

## Установка

1. Скачайте и распакуйте `dist/twitch-picture-in-picture.zip` в постоянную папку. Если используете исходники, папка проекта уже готова к установке — сборка и Node.js не нужны.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, внутри которой лежит `manifest.json`.
5. Откройте стрим или VOD на Twitch. Для уже открытой вкладки обновите страницу либо нажмите значок расширения.

ZIP нельзя просто перетащить в браузер: сначала распакуйте его. Не удаляйте выбранную папку после установки.

## Использование

- Нажмите **PiP** в правом верхнем углу видео.
- Или закрепите расширение в меню «Расширения» и нажмите его значок.
- Или нажмите **Alt+Shift+P** на вкладке Twitch.
- Повторное нажатие возвращает видео во вкладку. Также можно закрыть само окно PiP.

Окно можно перемещать и менять его размер. Видео продолжает использовать текущий плеер Twitch, его качество, звук и позицию VOD. Вкладка Twitch должна оставаться открытой. В PiP выводится видео; чат остаётся на странице. Набор кнопок в отдельном окне определяет Chromium.

Кнопка подхватывает плеер после перехода на другой канал или VOD внутри Twitch. Если сайт пересоздаёт видео и окно PiP закрывается, нажмите кнопку снова.

Встроенные Twitch-плееры на `player.twitch.tv` также получают кнопку PiP. Значок расширения и горячая клавиша рассчитаны на отдельную вкладку Twitch.

## Если не работает

- Сначала запустите видео и дождитесь загрузки изображения.
- Если горячая клавиша занята, измените её в `chrome://extensions/shortcuts`.
- При ошибке кнопка на видео показывает пояснение. У значка расширения появляется `!`; наведите на него курсор, чтобы прочитать причину.
- После изменения файлов нажмите «Обновить» на карточке расширения в `chrome://extensions`, затем обновите Twitch.
- Расположение окна поверх других приложений зависит от браузера и оконного менеджера ОС.

## Доступ к данным

Manifest V3. Автоматический скрипт работает только на `www.twitch.tv` и `player.twitch.tv`. Разрешения `activeTab` и `scripting` нужны для запуска через значок и горячую клавишу, включая вкладки, открытые до установки. Расширение не отправляет запросов на свои серверы, не собирает историю, не хранит данные аккаунта и не меняет сетевые запросы Twitch.

## Разработка и проверки

```sh
npm ci
npm test
npm run pack
```

Для тестов нужен установленный Chromium и графическая сессия. По умолчанию используется `/usr/bin/chromium`; другой путь можно задать переменной `CHROMIUM_PATH`.

Восемь браузерных тестов проверяют настоящее PiP для MediaStream и записанного WebM, сохранение позиции VOD, восстановление атрибута запрета PiP, замену плеера при SPA-переходах, выбор видимого видео, запуск обработчика значка, внешнее закрытие PiP и сообщения об ошибках. Тестовый Twitch-домен обслуживается локальной HTML-заглушкой; для имитации разрешения `activeTab` при клике тестовая копия манифеста получает доступ к этому домену. В установочном архиве этого дополнительного разрешения нет.

`npm run pack` создаёт ZIP только из рабочих файлов, иконок и этой инструкции. `python3 scripts/build_icons.py` пересоздаёт иконки без сторонних зависимостей.

Основа реализации: [Picture-in-Picture API](https://developer.chrome.com/blog/watch-video-using-picture-in-picture) и [изолированные content scripts Chromium](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts).
